01. Discovery

Unmask your
Attack Surface.

PacketPulse runs a two-phase scan - rapid TCP knock sweep to find live hosts, then full port enumeration only on confirmed targets. No wasted time, no false silence.

  • Two-phase scan: discover first, enumerate second
  • TCP fallback when ICMP is blocked by firewall
  • Configurable range from a single IP to full subnet
packetpulse — scan
$ python3 packetpulse.py

02. Intelligence

Banners.
Versions.
Context.

Every open port gets interrogated. PacketPulse grabs service banners, extracts server versions, detects TLS endpoints and categorises every finding across 9 service categories - all colour-coded.

  • Banner grabbing with HTTP Server header extraction
  • TLS/SSL detection on all secured ports
  • Multiple categories: Remote, Web, Database, Mail, DevOps…
  • Filter results live without rescanning

Stack.
